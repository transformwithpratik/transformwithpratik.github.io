# WS5 — Trend research & scripts

## Goal
Each week, turn what's trending in fitness into accurate, research-backed,
ready-to-shoot scripts for Instagram (WS2) and YouTube (WS4).

## Weekly process
1. Scan: Instagram/YouTube fitness trends, Google Trends (India), common client
   questions and DMs.
2. Shortlist 5 topics that fit the audience (busy professionals) and pillars.
3. Research each: prefer systematic reviews/meta-analyses and professional
   bodies (ACSM, ISSN, WHO, ICMR-NIN for Indian nutrition). Label evidence as
   established / emerging / unsupported. Real citations only, with links.
4. Write scripts using the SKILL.md template; flag claims that need caveats.
5. Add edit notes (cuts, B-roll, on-screen text, captions, music mood).
6. Hand off: append to WS2 calendar; long-form candidates go to WS4.

## Output format per topic
- Trend + why it's trending (source)
- Evidence summary (2–4 bullet points with citations)
- Verdict line for the hook ("works / partly / myth")
- Reel script (30–60s) + caption + CTA
- Optional long-form outline

## Editing support
Scripts include edit notes. An OpusClip connector is available in some
sessions for transcripts, captions, B-roll and exports — use when Pratik
supplies raw footage.
